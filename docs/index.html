开始你的第一次识别

  1. 选择视频与跳法

    推荐固定机位、单人全身、光线充足的视频。普通并脚跳选“双脚起落”，跑步式左右换脚跳选“交替脚跳”。支持 60 Hz 视频时间采样；低帧率原片不会凭空增加动作信息。

  2. 确认识别区域

    多人或带边框的录像，可框选跳绳者，身体和脚部都要包含在内。默认使用 Full 姿态模型，性能较低设备可改为 Lite。

  3. 开始识别，随时暂停

    骨架与关键点显示识别过程，黄色轨迹显示重心变化。双脚模式同时检查肩、髋和脚的起落，交替脚模式检查左右支撑脚切换。速度受设备性能影响，回放无声。

  4. 检查质量并回放

    “有效人体帧”是人体关键点满足可见性检查的帧数比例，不是准确率。“识别不确定”时请复核该片段。已识别片段不会重复累计；拖到未识别位置会先补齐。支持导出 CSV。

目前尚无人工标注原始视频的准确率评测，不能保证特定准确率。本工具估计人体起落或交替脚步数，不直接确认绳子通过脚底；交替脚模式也可能把原地跑步计入。镜头移动、遮挡、花式动作与丢帧可能造成误差。关闭或刷新后需重新导入。
